## Where to start

| Repository | What it is |
|---|---|
| [judgekit](https://github.com/mohammadi-hadi/judgekit) | Audit an LLM judge before you trust it — position, verbosity and self-preference probes with confidence intervals, validated on judges with implanted defects |
| [trajectory-judge](https://github.com/mohammadi-hadi/trajectory-judge) | What an LLM judge misses when an agent reaches the right answer the wrong way — fault injection, five judges compared, every verdict committed |
| [ml-foundations](https://github.com/mohammadi-hadi/ml-foundations) | ML fundamentals from scratch in numpy, each implementation checked against an independent reference and every number in the lessons regenerated by CI |
| [EvalMORAAL](https://github.com/mohammadi-hadi/EvalMORAAL) | Chain-of-thought and LLM-as-judge evaluation of moral alignment across 20 models — \*SEM 2026 |
| [spark-search-ranking](https://github.com/mohammadi-hadi/spark-search-ranking) | Counterfactual learning-to-rank for marketplace search logs in PySpark |
| [RA-DPO](https://github.com/mohammadi-hadi/RA-DPO) | Reliability-aware preference optimization and selective prediction under annotator disagreement |
