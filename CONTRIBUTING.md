# Contributing

Thanks for your interest in contributing. These are research repositories; contributions that improve reproducibility are especially valued.

## Reporting problems

- Open an issue describing what you ran, what you expected, and what happened.
- For problems with a specific script or notebook, include the Python version and the versions of the main libraries involved.

## Pull requests

- Keep changes focused: one fix or improvement per pull request.
- Match the style of the surrounding code.
- If a change affects results reported in an accompanying paper, please note that explicitly in the description.

## Questions

Where Discussions are enabled, questions are welcome there; otherwise open an issue. Contact options are listed at <https://mohammadi.cv>.
