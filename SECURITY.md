# Security Policy

These repositories contain research code and are not deployed services, but security reports are still taken seriously.

If you find a vulnerability (for example unsafe deserialization, a dependency with a known CVE that affects results, or leaked credentials), please report it privately via GitHub's "Report a vulnerability" button on the repository's Security tab, or through the contact options at <https://mohammadi.cv>.

Please do not open a public issue for security reports.
